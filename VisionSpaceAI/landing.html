AI Pipeline Processing

1. Video Upload

Capture a 360° spatial walkthrough of your room to provide full situational context.

Tech: Flask, HTML5 Video API
2. Preference Input

Define your vision by selecting styles, color palettes, and budget constraints.

Tech: JavaScript, JSON Schema
3. Frame Extraction

Processing the uploaded video to sample high-resolution interior frames.

Tech: OpenCV (python-opencv)
4. Frame Selection

Identifying unique walls and scenes using structural similarity (SSIM) analysis.

Tech: Scikit-Image, Hist-Diff
5. Image Preprocessing

Removing blurs via Laplacian variance check and normalizing lighting data.

Tech: OpenCV, NumPy
6. Object Detection

Recognizing furniture and room boundaries to maintain architectural scale.

Tech: YOLOv8 (Ultralytics)
7. Feature Extraction

Analyzing textures, materials, and existing decor styles using deep learning.

Tech: ResNet50 (PyTorch)
8. Preference Encoding

Transforming user choices into high-dimensional AI-readable vector tokens.

Tech: CLIP Text Encoder
9. Feature Fusion

Synchronizing visual room data with user style preferences for generation.

Tech: Tensor Concatenation
10. Prompt Generation

Synthesizing a precise generative instruction based on fused characteristics.

Tech: GPT-based Prompt Logic
11. Design Generation

Synthesizing photorealistic redesigns with architectural fidelity.

Tech: Stable Diffusion + ControlNet
